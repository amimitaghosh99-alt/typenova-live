## 💼 LinkedIn Launch Post

Most developers type every single day, yet typing practice tools have barely evolved past basic web forms.

Today, I’m thrilled to unveil **TypeNova** ⚡ — an open-source, ultra-low latency gamified typing suite built for engineers, gamers, and speed typists.

Key highlights engineered into TypeNova:
⚡ **Sub-2ms Mechanical Engine:** 120+ FPS input handling with zero layout thrashing.
🤖 **Autonomous AI Coach (Aru):** Identifies slow bigrams (e.g. `th`, `str`) and generates instant micro-drills to eliminate finger hesitation.
🎮 **3D CyberHands Progression:** Interactive physical finger mirroring in Three.js with RPG rank tiers from Novice to Singularity God.
🏁 **Real-time Multiplayer:** WebSocket-synchronized drag races with live keystroke replay curves.
🎧 **Acoustic Switch Synthesis:** Real mechanical switch profiles (Cherry MX Blue, Topre, Cyber Laser) synthesized via Web Audio API.

Built with React 19, TypeScript, Three.js, Tailwind CSS, and Supabase.

Check out the live demo: https://typenova-live.vercel.app
Source code: https://github.com/amimitaghosh99-alt/typenova-live
